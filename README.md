# Sigillum

App de finanças pessoais em um único arquivo HTML (`index.html`), publicado como artifact do Claude.

- Cada alteração do app vira um commit, então dá para voltar a qualquer versão anterior.
- Para restaurar: copie o `index.html` da versão desejada e republique.

## Ícone e splash (pasta `assets/`)

- `icon-only.png`: ícone completo 1024 px (loja e testes).
- `icon-foreground.png` + `icon-background.png`: ícone adaptativo do Android (símbolo dentro da zona segura).
- `icon-monochrome.png`: versão de uma cor para o ícone temático do Android 13+.
- `splash.png` e `splash-dark.png`: tela de abertura clara e escura.
- Arquivos `.svg` são a fonte editável.
